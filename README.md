# Warehouse Inventory System
- WIMS (Warehouse Inventory Management System) is a command-line application developed using Python to manage and track warehouse inventory efficiently. The system is designed to operate entirely in the terminal, making it lightweight, fast, and easy to run without requiring a graphical user interface.

- The main purpose of WIMS is to help users organize, monitor, and update stock records in a warehouse environment. It replaces manual inventory tracking methods with a digital system that improves accuracy, reduces errors, and speeds up inventory operations.

## Features
1. Animations
- Exit
- Loading
- Returning Main menu

2. Low Stock Sound
3. Insert Menu
4. Delete Menu
5. Update Menu
6. Display All items Menu
7. Display Sorting BY ID menu
8. Search BY ID
9. Search Price Range
